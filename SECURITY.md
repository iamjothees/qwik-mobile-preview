# Security Policy

## Supported Versions
Only the latest release on the `main` branch is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Qwik Mobile Preview:
1. **Do not open a public GitHub issue.**
2. Send an email to **iamjothees@gmail.com** with details of the vulnerability and steps to reproduce.
3. You will receive an acknowledgment within 48 hours.
4. A security patch will be prepared and released before public disclosure.
